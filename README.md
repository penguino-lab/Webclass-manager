# Webclass manager

**WebClassの講義ページ・教材画面・ダウンロード・保存後の資料閲覧を、まとめて使いやすくするブラウザ拡張機能。**

教材を開く、必要な資料を探す、PDFを保存する、保存した資料を見返す。Webclass managerは、こうした授業前後の操作をWebClass上のUI改善と専用ライブラリで支援します。現在の配布版は **v0.6.3** です。

[ダウンロード（ZIP）](https://github.com/penguino-lab/Webclass-manager/archive/refs/heads/main.zip) · [導入方法](#インストール) · [全機能ガイド](FEATURES.md) · [不具合報告](https://github.com/penguino-lab/Webclass-manager/issues)

WebClassの提供元・各大学による公式製品ではありません。対応する講義・教材画面へ改善を適用します。WebClassのすべてのページを書き換える機能や、大学側のシステムを変更する機能ではありません。

## どんな操作が変わる？

| 場面 | 拡張機能でできること |
| --- | --- |
| 講義の教材一覧 | 教材カードの広い範囲から開く、利用できる教材や期間設定のある教材に絞る、講義コードをコピーする |
| 教材を読む | 大きい目次から教材を切り替える、現在の教材を見分ける、閉じる操作を分かりやすくする |
| 資料を保存する | 添付資料と表示中PDFを文言付きの保存ボタンからダウンロードする |
| ファイルを整理する | 選んだ保存先に講義別フォルダーを作成し、進捗表示・重複確認を行う |
| 保存後に見返す | 専用ライブラリで検索・種類の絞り込み・お気に入り・PDFや画像のプレビューを使う |

### 講義ページ：探す・開く操作をスムーズに

- 教材名だけでなく、教材カードの余白からも教材を開けます。キーボードのTab・Enter・Spaceでも操作できます。
- **現在開ける教材だけ表示** と **期間が設定された教材だけ表示** を切り替えられます。両方の条件を組み合わせ、WebClass本来の検索とも併用できます。
- 利用できない教材をグレーと文言で区別します。初期状態では「現在開ける教材だけ表示」がONです。
- **講義コードをコピー** からコードをコピーできます。結果は同じボタン内に表示します。
- WebClassのホームへ戻るリンクのクリック範囲を広げています。
- 初回一覧の読み込み中はスケルトンを表示し、一覧が切り替わる際の配置の跳ねを抑えます。

### 教材画面：目次と保存ボタンを分かりやすく

- 目次を大きな行として表示し、教材名や行の余白から切り替えられます。現在の教材は青い背景と枠で示します。
- 添付リンクを **添付資料をダウンロード** ボタンとして表示します。
- PDFの保存アイコンに **表示中の教材（PDF）をダウンロード** と表示し、保存対象を分かりやすくします。
- 上部の帯から **× 資料を閉じる** を操作できます。目次上部の一部の重複操作は非表示にして操作領域を整理します。
- 名前のない教材や章だけの構成では、取得できる章名や補助表示を使って目次を操作しやすくします。

**自動整理をOFFにしても、対応する講義・教材画面のUI改善は適用されます。** 保存先の整理機能と画面の改善をそれぞれの目的で利用できます。

### ダウンロード：講義ごとに保存して見失いにくく

```text
選んだ保存先/
├─ 数学/
│  ├─ 第1回資料.pdf
│  └─ 演習.xlsx
└─ 統計学/
   └─ 第1回資料.pdf
```

保存先を一度選ぶと、その中に講義別フォルダーを作成します。PDFは取得できた教材名・節名から保存名を付け、Windowsで使えない文字も処理します。

保存中は進捗を表示し、完了通知は約5秒で消えます。同名資料が保存済みの場合は保存を止め、**再ダウンロードする** を押した場合だけ連番付きで保存します。

### ライブラリ：保存済みの資料を探して見返す

- フォルダ・すべての資料・お気に入りを切り替えて閲覧。
- ファイル名・フォルダ名で検索。フォルダ内の検索はサブフォルダも対象。
- PDF・PowerPoint・Word・Excel・その他を複数選んで絞り込み。
- 名前・更新日時・サイズで並べ替え、グリッド／一覧表示を切り替え。
- PDF・画像のサムネイルと詳細プレビュー、講義フォルダの最大4分割カバー。
- 星を1クリックしてお気に入りを登録・解除。
- 対応ファイルをブラウザの別タブで開く。
- 同じ画面の設定から保存先・自動整理・WebClass URL・授業名の表示を変更。

細かな表示動作や対応範囲は [全機能ガイド](FEATURES.md) にまとめています。

## インストール

1. [ZIPをダウンロード](https://github.com/penguino-lab/Webclass-manager/archive/refs/heads/main.zip)して展開します。
2. 展開したフォルダーを今後も残す場所へ移動します。
3. Chromeは `chrome://extensions`、Edgeは `edge://extensions` を開き、デベロッパーモードをONにします。
4. **パッケージ化されていない拡張機能を読み込む** で、`manifest.json`のあるフォルダーを選びます。
5. 拡張のポップアップから **ライブラリを開く → 設定** を開き、自分の大学のWebClassのベースURLを保存します。初期値には開発時の大学サイトが入っているため、必ず確認してください。
6. 対象WebClassへのアクセスを許可し、開いているWebClassのタブを再読み込みします。
7. ポップアップの **保存先を選ぶ** またはライブラリ設定の **データの保存場所 → 変更** から、資料専用の保存先を指定します。

Chrome 133以降が必要です。Edgeは同等のChromium機能を備えたバージョンが対象です。大学・WebClassのバージョンによって画面構造が異なるため、すべての環境での動作を保証するものではありません。ストアからの自動インストール・自動更新には対応していません。

## 最初に試すこと

1. WebClassへ通常どおりログインして講義を開き、教材カードと右側の絞り込みを確認します。
2. 教材を開き、大きな目次と文言付きのダウンロードボタンを確認します。
3. 資料を1つ保存し、指定先に講義フォルダーが作られたことを確認します。
4. ポップアップからライブラリを開き、検索やプレビューを試します。

教材が見つからない場合は **現在開ける教材だけ表示** 等の条件を解除してください。UIが合わない場合は拡張を無効化し、WebClassのタブを再読み込みすると元の表示で利用できます。

## 更新

1. 最新ZIPを取得して別の場所に展開します。
2. 現在の拡張フォルダーをバックアップし、同じ場所へ新しいファイルをコピーします。
3. 拡張機能管理画面で再読み込みし、WebClassとライブラリのタブも再読み込みします。

設定を保つため、通常は既存の拡張を削除せず更新してください。削除すると設定・お気に入りが失われます。保存済み資料は残ります。

## 対応範囲と制約

- 主なUI改善対象は講義の教材一覧と教材・PDF画面です。課題の自動提出、出席の自動操作、成績管理、通知の外部配信等は含みません。
- 大学ごとのDOM・認証・教材形式により、一部機能が動作しない場合があります。ダミーサイトでの自動検証と、実際の大学環境での確認は区別してください。
- 直接保存の主な対象はWebClassの添付資料とWebClass内PDFビューアの保存操作です。右クリック保存、外部サイト、Chrome内蔵PDFビューア等は通常保存になる場合があります。
- 選択フォルダーへの直接保存はChromeのダウンロード履歴に表示されません。ライブラリで閲覧するにはフォルダーの読み取り許可が必要です。
- ブラウザの保存先を使うモードでは、その下に `講義名/ファイル名` で保存します。ライブラリがブラウザの保存先を自動で読み取ることはできません。
- Office文書は種類アイコンで表示します。大きい資料等はプレビューを生成できない場合があります。
- 既存資料の移動・削除・名前変更、資料本文の全文検索、Windows既定アプリで開く機能は含みません。

## プライバシー・サポート

ID・パスワード・Cookieの独自取得や保存は行いません。資料はブラウザのログイン済みセッションで取得します。外部解析サービスへの送信機能はありません。

[権限とデータの説明](PRIVACY.md) · [不具合報告・開発手順](CONTRIBUTING.md) · [共有用の紹介文](SHARING.md)

不具合報告にはブラウザ・拡張のバージョンと再現手順を添え、パスワード・認証URL・授業資料は投稿しないでください。
