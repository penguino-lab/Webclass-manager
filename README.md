# Webclass manager

WebClassの画面を使いやすくし、講義資料のダウンロード・講義別の整理・保存後の検索をまとめて支援するブラウザ拡張機能です。現在のバージョンは **0.9.10** です。

**[最新版をダウンロード（ZIP）](https://github.com/penguino-lab/Webclass-manager/archive/refs/heads/main.zip)** · [インストール](#インストール) · [初期設定](#初期設定) · [更新方法](#更新方法) · [詳しい使い方](FEATURES.md)

| 使いたいこと | できること |
| --- | --- |
| WebClassを見やすくする | 7種類のテーマ、ヘッダー画像の切り取り、ホームのライブラリバナー、お知らせのティッカー |
| 教材を探して開く | 教材カード全体から開く、利用できる教材の絞り込み、講義コードのコピー、大きい目次 |
| 資料を保存する | 添付資料・表示中PDFの保存、開いている教材内の資料の一括ダウンロード、講義別フォルダーへの整理 |
| 保存した資料を見返す | ファイル名検索、種類の絞り込み、お気に入り、PDF・画像のプレビュー |

WebClassの提供元・各大学による公式製品ではありません。大学やWebClassのバージョンによって、利用できる機能が異なります。

## ダウンロード

利用するだけなら、**[配布用リポジトリのmainのZIP](https://github.com/penguino-lab/Webclass-manager/archive/refs/heads/main.zip)** を取得してください。GitHubアカウント、Git、Node.js、ビルド作業は不要です。

GitHubの画面から取得する場合は、[配布用リポジトリ](https://github.com/penguino-lab/Webclass-manager)で **main → Code → Download ZIP** を選びます。ZIPはダウンロード時点のmainの内容です。ブラウザの拡張機能ストアからの自動更新には対応していません。

## インストール

対応環境は **PC版Chrome 133以降**です。Edgeは同等のChromium機能を備えたバージョンが対象です。ブラウザの補助テストはChromiumを使います。

1. [最新版のZIP](https://github.com/penguino-lab/Webclass-manager/archive/refs/heads/main.zip)をダウンロードし、右クリックの **すべて展開** などで展開します。ZIPのままでは読み込めません。
2. 展開したフォルダーを、今後も残す場所へ移動します。例：`ドキュメント/Webclass-manager`。読み込み後もフォルダーを削除・移動しないでください。
3. Chromeなら `chrome://extensions`、Edgeなら `edge://extensions` をアドレスバーに入力します。
4. **デベロッパーモード**をONにし、**パッケージ化されていない拡張機能を読み込む** を選びます。Edgeでは **展開して読み込み** と表示される場合があります。
5. 展開先の **`manifest.json` が直接入っているフォルダー**を選びます。二重にフォルダーができた場合は内側を選んでください。
6. 拡張機能一覧で **Webclass manager / 0.9.10** と表示されることを確認します。
7. ブラウザの拡張メニューから「Web+」アイコンを固定すると、次の設定が行いやすくなります。

学校・組織の管理設定でデベロッパーモードや拡張機能の追加が禁止されている場合、この手順では導入できません。

## 初期設定

### 1. WebClassを開いてアクセスを許可する

1. 拡張を読み込んだ状態で、大学から案内されたWebClassを開きます。
2. **「このWebClassで使う」** という案内ウィンドウが自動で開きます。表示されたベースURLが自分の大学のものか確認します。
3. **このWebClassで使う** を押し、続いてChromeが表示するサイトへのアクセス確認を **許可** します。
4. ベースURLが自動登録され、開いているWebClassに画面の改善を適用します。ライブラリで **設定を保存** を押す必要はありません。

TCU以外のドメインや `https://lms.example.ac.jp/campus/webclass/` のような構成も検出します。URLの `/webclass/`、WebClassを示すホスト名、ページ名と既知のPHP入口を手がかりにするため、独自のURL形式では検出できない場合があります。認証サービスだけのページでは案内せず、WebClass本体へ移動してから検出します。検出URLには認証用クエリや教材IDを保存しません。

Chromeの正式な権限ダイアログにはボタン操作が必要なため、まず拡張の案内が開き、ボタンを押した後にChromeの確認へ進みます。**あとで** を選ぶと同じサイトの案内はそのブラウザセッション中に繰り返し表示しません。WebClass上でWeb+アイコンをクリックすると再度開けます。背景タブでは案内を開かず、そのタブを選んだときに表示します。

### 2. ライブラリを開く・必要な場合にURLを修正する

WebClass内の **ライブラリを開く**、またはツールバーの **Web+アイコンを右クリック → ライブラリを開く** を選びます。拡張機能の管理画面の **詳細 → 拡張機能のオプション** からも開けます。

自動検出されないURLでは、ライブラリ左下の **設定 → WebClassのベースURL → 設定を保存** から手動登録できます。設定するのは `https://webclass.example.ac.jp/webclass/` のような共通部分で、認証URLや個別教材のURLではありません。

拡張アイコンの通常クリックは、初期設定ではアクセスが必要なWebClassの初回案内を開き、それ以外では登録した大学のベースURLを開きます。初期値のTCUを使う場合はTCUのSAMLログイン画面を開きます。ライブラリの **設定 → 拡張アイコンでライブラリを開く** を有効にして **設定を保存** を押すと、通常クリックでライブラリを直接開けます。

初回案内は、ページ全体の読み込み完了や資料保存の待ち列、Chromeのアクセス要求表示の完了を待たずに開きます。背景タブでは、そのタブを選ぶまで案内を表示しません。

### 3. 資料の保存先を選ぶ

ライブラリの初期画面にある **保存先フォルダーを選んで、はじめましょう** をクリックして、資料の保存先を選びます。はじめてなら、空の専用フォルダーを作って選ぶのがおすすめです。授業ごとのフォルダーは自動で作成します。読み取り・書き込みを許可すると、その場で保存先が登録されます。あとから **設定 → データの保存場所 → 変更** で選び直すこともできます。

```text
選んだ保存先/
├─ 数学/
│  ├─ 第1回資料.pdf
│  └─ 演習.xlsx
└─ 統計学/
   └─ 第1回資料.pdf
```

**ブラウザの保存先を使用** に切り替えると、ブラウザのダウンロード先の下へ `講義名/ファイル名` で保存します。ライブラリで資料を表示するには、そのフォルダーを別途選び、読み取りを許可する必要があります。

標準では、選んだ保存先と、その直下の授業フォルダーに直接入っている資料だけを読み込みます。授業フォルダー内にさらにフォルダーを作っている場合は、**設定 → 表示 → 授業フォルダー内のサブフォルダーも読み込む** をONにすると、その下も検索・表示の対象になります。OFFでは深いフォルダーの中身を読み取りません。

時間が経ってフォルダーへの許可が切れた場合は、ライブラリの **Chromeでアクセス許可を確認** を押し、Chrome側で **サイトアクセス時は常に許可** を選んでください。表示と保存の許可をまとめて要求します。**今回のみ許可** は一時的な許可です。「常に許可」の選択肢を表示する条件や許可の保持はChromeが管理し、拡張から自動選択することはできません。[Chromeの説明](https://developer.chrome.com/blog/persistent-permissions-for-the-file-system-access-api)も参照してください。

## 基本の使い方

1. WebClassで講義を開き、教材カードをクリックします。教材が見つからない場合は **現在開ける教材だけ表示** などの絞り込みを解除してください。
2. **添付資料をダウンロード** または **表示中の教材（PDF）をダウンロード** を押します。開いている教材をまとめて保存する場合は、目次下部の **この教材の資料を一括ダウンロード** を使います。章を確認している間は手動で切り替えずにお待ちください。
3. WebClassホームのバナー、ヘッダーの **ライブラリを開く**、またはアイコンの右クリックメニューからライブラリを開きます。検索・種類フィルター・お気に入りで資料を探せます。
4. ヘッダーのパレットアイコンと **テーマ** からテーマを切り替えられます。初回は **シルバー** が選択され、保存済みの選択は維持します。「デフォルト」はWebClass側の配色（青・グレーなど）を使います。メニューの **バナー画像を選択** で自分の画像を切り取り、ヘッダーに設定できます。

同名の資料がある場合は保存を止め、**再ダウンロードする** を押したときだけ連番付きで保存します。自動整理をOFFにしても画面の改善は利用できます。詳細は [全機能ガイド](FEATURES.md) を参照してください。

## 更新方法

拡張アイコンをクリックしたとき、WebClassへアクセス・タブに戻ったとき、ライブラリを開いた・タブに戻ったときに、公開版のバージョンを確認します。自動通信は全タブ共通で1分に1回までにまとめ、画面表示や移動を待たせません。新版があればWebClassの上部とライブラリのヘッダーに更新バナーを表示します。現在のバージョンは設定のアップデート欄で確認できます。**設定 → アップデート → 更新を確認** からすぐに確認することもできます。案内を閉じると同じ版は再通知せず、次の新版で再び表示します。通信できなくてもライブラリの利用は続けられます。この通知機能は0.9.2以降で利用できます。

ZIPから導入した拡張のため、バナーから更新手順を確認し、次の操作で更新してください。拡張のファイルを自動で書き換える機能はありません。

1. [最新のmainのZIP](https://github.com/penguino-lab/Webclass-manager/archive/refs/heads/main.zip)を取得し、現在の拡張フォルダーとは別の場所に展開します。
2. 現在の拡張フォルダーをバックアップします。保存済みの講義資料は拡張フォルダーの外に置いてください。
3. 読み込み済みの拡張フォルダーと同じ場所に、新版の `manifest.json` と同梱ファイル・サブフォルダーをまとめて上書きします。新しいフォルダーが内側に入る形にならないようにしてください。
4. `chrome://extensions` または `edge://extensions` で対象拡張の **再読み込み** を押し、バージョンを確認します。
5. WebClassとライブラリのタブを再読み込みします。追加の権限確認があれば内容を確認して許可してください。

設定とお気に入りを保つため、通常は既存の拡張を削除せず、同じフォルダーを更新してください。削除するとブラウザ内の設定等は失われますが、保存済みの資料は残ります。

0.9.4以前では、0.9.5での拡張名変更により更新通知が新版を認識できない場合があります。通知が出なくても、上記のZIPによる手動更新を行ってください。ダウンロード済みの古いZIP・展開先は自動では更新されません。READMEより古い版が表示される場合は、新しく取得したZIPの `manifest.json` と、ブラウザが読み込んでいる拡張フォルダーを確認してください。

## 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 読み込み時にmanifestが見つからない | ZIPを展開し、`manifest.json` が直接入っているフォルダーを選んでください。 |
| アイコンを押してもライブラリが開かない | 右クリックの **ライブラリを開く** を使ってください。通常クリックは初回案内または登録した大学を開きます。 |
| WebClassの表示が変わらない | WebClass上でWeb+アイコンをクリックし、初回案内からアクセスを許可してください。検出されない場合は設定でベースURLを手動登録します。 |
| 教材が見えなくなった | 講義画面の絞り込み条件を解除してください。 |
| 保存できない・資料が表示されない | 保存先のアクセス権を確認し、**アクセスを許可** または設定の **変更** で選び直してください。外部で追加した資料は **更新** で読み込み直せます。 |
| 画面の改善を一時停止したい | ブラウザの拡張機能管理画面で拡張をOFFにし、WebClassを再読み込みしてください。 |

## 対応範囲・プライバシー

- 大学の認証・教材形式・画面構造により調整が必要な場合があります。ダミーサイトの自動テストと大学の実環境での動作確認は別です。
- 一括ダウンロードの対象は**現在開いている教材内**の添付資料とPDFです。講義全体や別教材は対象に含みません。
- 主な直接保存対象はWebClassの添付資料とWebClass内PDFビューアです。外部サイト・右クリック保存などは通常保存になる場合があります。選択フォルダーへの直接保存はブラウザのダウンロード履歴に表示されません。
- Office文書は種類アイコンで表示します。既存ファイルの移動・削除・名前変更、資料本文の全文検索、自動提出・自動出席は行いません。
- 資料や設定・ヘッダー画像は利用者のPC内に保存します。外部解析サービスへの送信機能はありません。詳しくは [権限とデータ](PRIVACY.md) を参照してください。
