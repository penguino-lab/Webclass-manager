# Webclass manager

WebClassから保存する授業資料を講義ごとのフォルダーへ整理し、検索・お気に入り・PDFプレビューで閲覧できるChrome/Edge向け拡張機能です。配布版は **v0.6.3** です。

WebClassの提供元や各大学による公式の拡張機能ではありません。大学・WebClassのバージョンによって対応状況が異なります。

## インストール

1. このリポジトリの **Code → Download ZIP** を選び、ZIPを展開します。
2. 展開したフォルダーを、今後も残す場所へ移動します。
3. Chromeでは `chrome://extensions`、Edgeでは `edge://extensions` を開き、デベロッパーモードをONにします。
4. **パッケージ化されていない拡張機能を読み込む** から、`manifest.json`のあるフォルダーを選びます。
5. ポップアップの **ライブラリを開く → 設定** で、自分の大学のWebClassのベースURLを保存します。初期値には開発時の大学サイトが入っているため、必ず確認してください。
6. 対象のWebClassへのアクセスを許可し、WebClassのタブを再読み込みします。
7. **保存先を選ぶ** またはライブラリ設定の **データの保存場所 → 変更** から資料専用のフォルダーを指定します。

Chrome 133以降が必要です。Edgeは同等のChromium機能を備えたバージョンで利用してください。大学サイトとWindowsの実フォルダーピッカーでの動作確認が必要です。

## 使い方

WebClassへ通常どおりログインし、教材の **添付資料をダウンロード** または **表示中の教材（PDF）をダウンロード** を押します。

```text
選んだ保存先/
├─ 数学/
│  ├─ 第1回資料.pdf
│  └─ 演習.xlsx
└─ 統計学/
   └─ 第1回資料.pdf
```

保存中は進捗を表示します。同じ資料が保存済みの場合は停止し、**再ダウンロードする** を押した場合だけ連番付きで保存します。既存ファイルを上書きしません。

ライブラリでは検索、種類による絞り込み、並べ替え、お気に入り、PDF・画像のプレビューを利用できます。ファイル名を押すと詳細を表示し、サムネイルを押すと対応する資料をChromeの別タブで開きます。

設定では保存先、自動整理のON/OFF、WebClassのベースURL、授業名の表示方法を変更できます。

## 更新

1. 最新のZIPを取得して別の場所に展開します。
2. 現在の拡張フォルダーをバックアップし、同じ場所へ新しいファイルをコピーします。通常は拡張機能の削除・再登録は不要です。
3. 拡張機能管理画面で再読み込みし、WebClassとライブラリのタブも再読み込みします。

拡張を削除すると設定・お気に入りが失われます。保存済みの授業資料は残ります。

## 保存方法と制約

選択フォルダーには講義別フォルダーを直接作成します。この方式の保存はChromeのダウンロード履歴に表示されません。ブラウザの保存先を使用する場合は、その下に `講義名/ファイル名` で保存します。ライブラリで資料を一覧表示するには保存先フォルダーの指定が必要です。

- 大学ごとのDOMや認証方式の違いにより、取得や整理が動作しない場合があります。
- 主な対象はWebClassの添付資料とWebClass内PDFビューアの保存操作です。右クリック保存、外部サイト、Chrome内蔵PDFビューア等は通常保存になる場合があります。
- フォルダーへの許可が切れた場合は、設定から選び直してください。
- Office文書・ZIP等は種類アイコンで表示します。Windowsの既定アプリで直接開く機能、移動・削除・名前変更、資料本文の全文検索はありません。
- 大きいPDF・画像や読み取れないファイルはプレビューを生成できない場合があります。
